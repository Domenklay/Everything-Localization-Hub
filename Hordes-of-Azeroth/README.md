# HordesRU v0.8 — перевод наград и способностей

Аддон русификации Hordes of Azeroth 0.6.x. Тестовая версия, перевод неполный.

## Установка
1. Закройте Hordes of Azeroth и его лаунчер.
2. Перенесите папку `benilla-config` из ZIP в корень игры с заменой файлов.
3. Запустите через официальный HoALauncher. Должно появиться сообщение `[HordesRU] v0.8 loaded (reward cards supported)`.
4. `/hru` — повторная проверка видимого интерфейса.

**Не ставьте старый `patch-Y.MPQ`. `patch-z.MPQ` — игровой файл, не удаляйте его.**

## Что исправлено
- Вместо попытки перевести уже готовый HTML интерфейса аддон подключается к функции `VanillaBonkOffer.FitCard` перед формированием карточек улучшений/новых способностей.
- Переведены заголовки и описание "Прицельного выстрела", "Вожака стаи" и "Пиромана", а также ряд актуальных описаний из серверных обновлений.
- Для русских карточек используется более компактный размер шрифта (заголовок 14, описание 9–11), одинаковый при измерении текста и отображении.
- Данные оригинальной карточки, идентификаторы и логика выбора не изменяются: формируется временная копия описания.
- Исправлены цветные подписи `New spell` и `New passive`, добавлены числовые шаблоны горения и кровотечения.

Оригинальные файлы не модифицируются. Для удаления удалите `benilla-config/AddOns/HordesRU`.
Не все способности переведены. Работа в клиенте пока не подтверждена; в первую очередь проверьте выбор наград охотника и пассивки `Pyromaniac`.
