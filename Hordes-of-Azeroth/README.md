# HordesRU — перевод Hordes of Azeroth

## Актуальная версия: v1.0 (тестовая)

Перевод игрового интерфейса, магических талантов, карточек наград и ряда способностей. Дополнительные переводы для мага, чернокнижника и подсказок; часть серверных описаний ещё остаётся английской.

Шрифт по умолчанию — встроенный NotoSansKR-Regular.otf (`/hru font kr`).

## Установка

Распакуйте `benilla-config/AddOns/HordesRU` из архива в корень Hordes of Azeroth рядом с `WoW.exe`. Не заменяйте оригинальные `.toc`, MPQ и исполняемые файлы. Запускайте обычным лаунчером. Вход в игру должен показать `[HordesRU] v1.0 loaded`.

**Исходники:** [HordesRU/HordesRU.lua](HordesRU/HordesRU.lua) и [HordesRU/HordesRU.toc](HordesRU/HordesRU.toc).

**Важно:** v1.0 локально проверена на синтаксис Lua и на тестовых текстах. Полная проверка раскладки шрифтов в клиенте Hordes ещё требуется; русификация не завершена.
