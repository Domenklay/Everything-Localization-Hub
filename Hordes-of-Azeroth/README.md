# HordesRU 1.18 FULL — русификатор Hordes of Azeroth 0.6.x

**Один полный установочный архив.** Никаких отдельных фиксов, BAT, PowerShell, загрузчиков или изменённых EXE/MPQ. Внутри находятся все 7 Lua-модулей и HordesRU.toc.

## Установка

1. Закройте игру и лаунчер.
2. Удалите старый `benilla-config\AddOns\HordesRU`; если есть отдельно установленный `benilla-config\AddOns\HordesRU_Expansion`, удалите и его.
3. Распакуйте папку `benilla-config` из ZIP в папку игры рядом с `WoW.exe`.
4. Запустите игру. Команда `/hrucheck` должна показать `main catalogue: OK`.
5. Основной шрифт — компактный Noto Sans KR. При необходимости: `/hru font kr`, затем `/reload`.

## Исправления v1.18

- Перевод текстов карт Новолуния **до** вёрстки SimpleHTML: теперь экран сундука использует полный словарь из `HordesRU_Expansion.lua`, в том числе описание карты «Гномский луч смерти».
- Редкость `Common/Uncommon/Rare/Epic/Legendary` больше не остаётся английской внутри русских названий.
- Кнопки «Переброс (N)» и «Пропуск (N)» получили компактные подписи и шрифт размером 10, чтобы не перекрывать подсказки клавиш R/X в штатной ширине 120 пикселей.
- Не изменены стоимость, количество перебросов, горячие клавиши, игровые награды и данные сервера.
- Сохранены исходные переводы 650 названий и описаний талантов, способности, символы, предсказания и остальные экраны предыдущей полной сборки.
