# Hordes of Azeroth — русификатор HordesRU v1.13

Единый аддон: HordesRU 1.7 + расширение интерфейса 1.10/1.11 + описания способностей 1.12 + символы 1.13. Совместим с Hordes of Azeroth 0.6.x (WoW 1.12.1 enUS).

## Полная установка из GitHub

1. Полностью закройте игру и HoALauncher.
2. На [главной странице](https://github.com/Domenklay/Everything-Localization-Hub) выберите **Code → Download ZIP**.
3. Из архива возьмите папку `Hordes-of-Azeroth/HordesRU`.
4. В `benilla-config/AddOns` удалите только старые папки `HordesRU` и `HordesRU_Expansion` (если они есть). Не трогайте оригинальный `HordesOfAzeroth`.
5. Поместите новую папку `HordesRU` в `benilla-config/AddOns/` рядом с оригинальным аддоном. Не создавайте двойную вложенность `HordesRU/HordesRU`.
6. Запустите игру.

Итоговая структура: `benilla-config/AddOns/HordesRU/` должна содержать `HordesRU.lua`, `HordesRU_Overlay.lua`, `HordesRU_FullData.lua`, `HordesRU_Expansion.lua`, `HordesRU_Abilities.lua`, `HordesRU_Glyphs.lua`, `HordesRU.toc`.

## Обновление поверх 1.11 / 1.12

Для уже установленной 1.11 достаточно добавить `HordesRU_Abilities.lua` и `HordesRU_Glyphs.lua`, заменив `HordesRU.toc`. Если установлена 1.12, достаточно модуля `HordesRU_Glyphs.lua` и нового TOC. Старые основные файлы не удалять.

## Компактный шрифт

Используется **Noto Sans KR** из оригинального Hordes. Команды: `/hru font kr` и `/reload` — вернуть компактный KR; `/hru font sc` — альтернативный SC; `/hru` — повторная проверка; `/hruexp` — отчёт о непереведённых строках.

## Содержимое версии 1.13

- Полный каталог талантов: 650 названий и 650 описаний.
- Каталог способностей `bonk_weapon`: 315 описаний, включая три версии «Перевоплощения».
- Каталог символов `bonk_glyph`: 32 названия, 32 описания и 5 отрицательных эффектов.
- Карточки выбора символов: перевод редкости, подсказок и подзаголовков с данными из сервера.
- Сохранены переводы карт Новолуния, предсказаний Сейджа, улучшений Никса, игровых подсказок и интерфейса.

**Ограничение:** полной локализации сервера и всех новых предметов пока нет. Русификатор изменяет только отображение, не изменяя `WoW.exe`, MPQ или исходный аддон.

Оригинальный каталог: [jonhaldors/hordes-of-azeroth](https://github.com/jonhaldors/hordes-of-azeroth). Проверены Lua-синтаксис и тестовые сценарии интерфейса; запуск 1.13 в самой игре ещё не подтверждён.
