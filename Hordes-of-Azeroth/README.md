# HordesRU v0.6 (экспериментальный русификатор)

Для Hordes of Azeroth 0.6.x и отдельного клиента Benilla. Русификатор НЕ меняет WoW.exe, штатный аддон, MPQ, базу данных и файлы лаунчера.

Установка: полностью закрыть игру; скопировать папку benilla-config из архива в КОРЕНЬ установленной игры с заменой существующего HordesRU. Не копировать в Interface/AddOns. Удалить старый Data/patch-Y.MPQ, если устанавливался прошлый MPQ-вариант; patch-z.MPQ (игровой) НЕ удалять. Запустить через обычный HoALauncher.

Проверка: после входа персонажем должна появиться строка '[HordesRU] v0.6 loaded'. Команда /hru запускает повторный проход по видимому интерфейсу.

Изменения v0.6: устранена несовместимость с Lua 5.0: вместо отсутствующей string.match используется string.find через MatchCaptures. Это исправляет ошибку при обработке текста. Словарь и обработка талантов из v0.5 сохранены.

Ограничения: перевод частичный; имена NPC, часть предметов и серверных строк не охвачены; текст на экране выбора персонажа и в лаунчере остаётся английским. Реальный запуск v0.6 пользователем не проверен. Сохраняются права разработчиков на исходные файлы.

Обновления лаунчера могут изменять игровые тексты; словарь потребует актуализации.

Исходник игры: https://github.com/jonhaldors/hordes-of-azeroth

## Исходники

- `HordesRU/HordesRU.lua` — словарь и обработчик интерфейса, Lua 5.0.
- `HordesRU/HordesRU.toc` — манифест аддона.

Сборка распространяется отдельным ZIP-архивом; версия v0.6 также доступна в текущем чате.
