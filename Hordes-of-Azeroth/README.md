# HordesRU v0.9

Частичная русификация Hordes of Azeroth 0.6.x. Для установки скопируйте папку `benilla-config` из архива в корень игры и замените предыдущую версию аддона. Никакие оригинальные файлы, `WoW.exe` и MPQ не меняются.

## Что нового

- Русские названия и описания талантов чернокнижника, в том числе «Тлеющие угли» и «Мастер демонологии», подсказки горения и способности беса.
- Локализация карт Новолуния и укороченные русские названия для маленьких карточек.
- Более компактные шрифты и пересчёт высоты подсказок, чтобы текст не выходил за границы.
- Два встроенных кириллических шрифта Hordes: `/hru font kr` (по умолчанию) и `/hru font sc` (прежний), выбор сохраняется. После переключения перезапустите игру.
- `/hru` повторно проверяет видимый интерфейс.

## Ограничения

Это тестовый перевод без полной русификации серверных описаний. Проверка непосредственно в клиенте требуется. При проблемах удалите `benilla-config/AddOns/HordesRU`; не удаляйте игровой `patch-z.MPQ`.
