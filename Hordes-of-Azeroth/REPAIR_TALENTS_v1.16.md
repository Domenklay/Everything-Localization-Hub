# Восстановление перевода талантов — HordesRU 1.16

Если `/hrucheck` сообщает `main catalogue: MISSING`, файл `HordesRU_FullData.lua` отсутствует, не запускается или не загрузил каталог. Частичные архивы 1.13–1.15 содержали только обновления: их нельзя использовать как самостоятельную установку.

## Полная установка

1. Закройте игру.
2. Получите **весь комплект** `HordesRU`, а не только файлы из патча. Основные модули: `HordesRU.lua`, `HordesRU_Overlay.lua`, `HordesRU_FullData.lua`, `HordesRU_Expansion.lua`.
3. Скопируйте эти четыре файла в `benilla-config/AddOns/HordesRU/` рядом с `WoW.exe`. Исходные модули опубликованы в [каталоге проекта](HordesRU/).
4. Добавьте обновления 1.12–1.15: `HordesRU_Abilities.lua`, `HordesRU_Glyphs.lua`, `HordesRU_Chest.lua` и `HordesRU_TalentRecovery.lua`. Для последнего используйте `HordesRU.toc`, который содержит все восемь модулей в этом порядке.
5. Уберите старую отдельную папку `HordesRU_Expansion`, если она ещё осталась, чтобы не загружать дубли.
6. Запустите клиент и введите `/hrucheck`. Ожидается `main catalogue: OK`. Для компактного шрифта: `/hru font kr` и `/reload`.

### Файлы и зависимости

Оригинальный `HordesOfAzeroth`, клиент и MPQ изменять не требуется. Сначала должны загрузиться четыре базовых модуля, а только затем новые файлы перевода способностей и карточек. Обычный пакет 1.15 НЕ содержит основного `HordesRU_FullData.lua`, поэтому сам по себе не исправляет статус `MISSING`.

Восстановительный установщик 1.16 поставляется отдельно ZIP-файлом. Он загружает проверенные версии базовых модулей с GitHub и устанавливает их вместе с локальными патчами только после проверки полноты загрузки. После установки старые файлы сохраняются в резервной копии.

Если полный набор файлов есть, но `MISSING` остаётся, включите отображение ошибок Lua командой `/console scriptErrors 1`, затем `/reload` и проверьте первую ошибку: возможно, каталог не выполнился из-за ошибки Lua.

Проверка в самом клиенте должна быть выполнена пользователем.
