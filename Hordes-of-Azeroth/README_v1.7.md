HordesRU v1.7 — единая русификация Hordes of Azeroth (0.6.x)

Установка:
1. Закройте игру и HoALauncher.
2. Удалите ТОЛЬКО старую папку benilla-config/AddOns/HordesRU.
3. Распакуйте benilla-config из ZIP в корень игры рядом с WoW.exe.
4. Запустите игру как обычно. Сообщение: [HordesRU] v1.7: полный каталог талантов подключён.

Это полноценный установочный архив: старые версии v1.3–v1.6 больше не нужны.
Три встроенных Lua-модуля загружаются из собственного HordesRU.toc.
Шрифт kr сохранён. Оригинальные WoW.exe, MPQ и файлы Hordes не изменяются.

Покрытие официального каталога: 650/650 названий талантов, 650/650 описаний талантов.
Остальные разделы НЕ полностью переведены: например, большинство описаний заклинаний, заданий и предметов.
Неизвестные данные сервера не заменяются непроверенными фразами.
